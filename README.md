# sportdbdev.rs

[![Crates.io](https://img.shields.io/crates/v/sportdbdev.svg)](https://crates.io/crates/sportdbdev)
[![docs.rs](https://img.shields.io/docsrs/sportdbdev)](https://docs.rs/sportdbdev)
[![CI](https://github.com/pilgrimagesoftware/sportdbdev.rs/actions/workflows/ci.yaml/badge.svg)](https://github.com/pilgrimagesoftware/sportdbdev.rs/actions/workflows/ci.yaml)
[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE.md)

This is a Rust client for accessing the [sportdb.dev](https://sportdb.dev) API, which surfaces
live sports data (competitions, fixtures, results, standings, live odds, match events/stats/
lineups, players, and teams) sourced from Flashscore.

## Usage

Add this to your `Cargo.toml`:

```toml
[dependencies]
sportdbdev = "0.1"
```
